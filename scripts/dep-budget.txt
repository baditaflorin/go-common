# Third-party dependency budget for the small packages many services import.
# Enforced by scripts/dep-budget.sh (the `validate` step); the measurements are in
# docs/dependencies.md.
#
# Syntax: the package (path relative to the module root), then the third-party
# modules (module paths, no versions) it may reach through its transitive, non-test
# imports. A package may have several lines. `@other` allows whatever package `other`
# is allowed. Anything after `#` is a comment. A package with nothing after its name
# is stdlib-only: it, and the go-common packages it imports, may not use any
# third-party module.
#
# This is a ratchet, not a target: each set is what the package reaches today.
# CI fails when a package reaches a module that is not listed for it. Fix that by
# moving the code that needs the module into a package that already depends on it
# (the usual answer), or, if the dependency is intended, add the module here and give
# the reason in the pull request. When a dependency goes away, delete its line too.
#
# `scripts/dep-budget.sh --print` shows every package's current set in this syntax;
# `scripts/dep-budget.sh --write-doc` refreshes docs/dependencies.md after an edit.
